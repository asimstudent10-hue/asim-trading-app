ASIM TRADING ANALYSIS APP - STARTER

This is the first mobile-app build.
Included:
- Pair selector
- 1m / 5m / 15m timeframe selector
- Candlestick-style chart screen
- RSI / EMA / MACD area
- BUY / SELL / WAIT analysis screen
- Indicator list
- Signal history area

IMPORTANT:
The chart currently uses demo data. The next build step is to connect a real-time Forex data provider and then calculate the indicators from real candles.

This project is made with Expo/React Native.
